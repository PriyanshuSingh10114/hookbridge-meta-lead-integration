# Meta Webhooks & HMAC Signature Verification

## 1. Webhook Handshake Protocol (`GET /webhooks/meta`)

When registering a webhook callback URL in the Meta Developer Portal, Meta immediately sends an HTTP GET request to verify ownership:

```http
GET /webhooks/meta?hub.mode=subscribe&hub.verify_token=hookbridge_verify_token_secure_2026&hub.challenge=1158201444
```

### Handler Requirements:
1. Verify `hub.mode === 'subscribe'`.
2. Confirm `hub.verify_token === process.env.META_VERIFY_TOKEN`.
3. Respond with HTTP 200 containing the raw `hub.challenge` string in the response body.
4. If tokens do not match, reject with HTTP 403 Forbidden.

## 2. Inbound Lead Notification Payload (`POST /webhooks/meta`)

When a lead ad form is submitted, Meta dispatches a POST request:

```json
{
  "object": "page",
  "entry": [
    {
      "id": "1029384756",
      "time": 1700000000,
      "changes": [
        {
          "field": "leadgen",
          "value": {
            "ad_id": "4455667788",
            "form_id": "9988776655",
            "leadgen_id": "123456789012345",
            "created_time": 1700000000,
            "page_id": "1029384756"
          }
        }
      ]
    }
  ]
}
```

> [!IMPORTANT]
> The webhook contains **only the `leadgen_id` pointer**, not the user's name, email, or phone. This metadata must be extracted to trigger the Graph API query.

## 3. Cryptographic Signature Verification (`X-Hub-Signature-256`)

Meta includes an `X-Hub-Signature-256` HTTP header formatted as `sha256=<hex_digest>`. This signature is generated by hashing the raw payload bytes with your `META_APP_SECRET`.

### Critical Implementation Rule: Raw Body Capture
Standard JSON body parsing deserializes and re-serializes payload keys, changing whitespace and attribute order. Validating HMAC against re-stringified JSON (`JSON.stringify(req.body)`) fails unpredictably. You must capture the raw incoming Buffer:

```javascript
// Express application setup
app.use(
  express.json({
    verify: (req, res, buf) => {
      req.rawBody = buf;
    }
  })
);
```

### Constant-Time Verification Middleware:
```javascript
const crypto = require('crypto');

const verifyWebhookSignature = (req, res, next) => {
  const appSecret = process.env.META_APP_SECRET;
  const signatureHeader = req.headers['x-hub-signature-256'];

  if (!signatureHeader) {
    return res.status(401).json({ error: 'Missing X-Hub-Signature-256 header' });
  }

  const [prefix, signature] = signatureHeader.split('=');
  if (prefix !== 'sha256' || !signature) {
    return res.status(401).json({ error: 'Invalid signature format' });
  }

  const rawBody = req.rawBody;
  if (!rawBody) {
    return res.status(400).json({ error: 'Missing raw payload buffer' });
  }

  const hmac = crypto.createHmac('sha256', appSecret);
  hmac.update(rawBody);
  const expectedSignature = hmac.digest('hex');

  const signatureBuffer = Buffer.from(signature, 'hex');
  const expectedBuffer = Buffer.from(expectedSignature, 'hex');

  if (
    signatureBuffer.length !== expectedBuffer.length ||
    !crypto.timingSafeEqual(signatureBuffer, expectedBuffer)
  ) {
    return res.status(403).json({ error: 'Invalid webhook signature' });
  }

  next();
};
```
